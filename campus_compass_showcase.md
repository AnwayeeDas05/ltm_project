## 🎯 Project Summary

| Aspect | Detail |
|--------|--------|
| **AI Assistant Name** | Campus Compass |
| **Tagline** | *"Navigating every student's journey from campus to career"* |
| **Problem Solved** | 60%+ engineering graduates unplaced due to career/prep gaps |
| **AI Modules** | 6 (Career Navigator, Resume Analyzer, Mock Interview, Skill Gap Detector, Placement Tracker, Mentor Matching) |
| **Target Users** | UG/PG students, TPO officers, Faculty advisors, Alumni mentors |
| **Key AI Technology** | Gemini Pro + LangChain + Pinecone RAG + spaCy NLP |
| **Architecture** | Microservices + Cloud-native (GCP) + React Native + FastAPI |
| **Demo Type** | Fully interactive multi-module AI chat prototype |

## 🚀 How to Run the Interactive Demo

1. Open the file in your browser:  
   `file:///Users/asitkumardas/.gemini/antigravity-ide/scratch/campus-compass/index.html`

2. Click **"Launch Demo"** or scroll to the **"Live Demo"** section

3. Select a module from the left panel (Career Navigator, Resume Analyzer, etc.)

4. Use the **Quick Prompts** or type your own question

5. **Try these example prompts:**
   - `"I want to become a Data Scientist"`
   - `"How do I improve my ATS score?"`
   - `"Start an Amazon SDE interview"`
   - `"Show upcoming placement drives"`
   - `"What skills do I need for Google?"`

---

> [!TIP]
> The app works completely offline — no server needed. All AI responses are pre-engineered with realistic, detailed content for every module.
